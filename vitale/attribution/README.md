# Google Maps attribution

`google-maps.svg` é o arquivo oficial `GoogleMaps_Logo_DarkGray.svg`, copiado sem alterações do pacote [Google Maps attribution assets](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip), obtido em 20/11/2026.

Uso: altura 18px, proporção original, área livre de 10px em cima e nos lados e 5px abaixo, alt `Google Maps`. [Regras oficiais](https://developers.google.com/maps/documentation/places/web-service/policies#google_maps_attribution_requirements).
